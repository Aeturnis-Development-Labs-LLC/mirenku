# v0.4.0 Security Features - Deferred Items

## Overview
Following "The Mirenku Way", we're implementing essential security in v0.4.0 while deferring non-critical enhancements to maintain development velocity and focus on user features.

## Security Implementation Status

### ✅ Implemented in v0.4.0
1. **Localhost-only binding**
   - Server only accepts connections from 127.0.0.1/localhost
   - No external network access
   - Critical for user privacy

### 🔧 To Implement in v0.4.0 (Phase 3 - Browser Extension)
1. **Basic Origin Validation**
   - Accept only chrome-extension:// and moz-extension:// origins
   - Reject any http/https origins
   - Simple implementation in extension phase

### 📋 Deferred to Future Versions

#### v0.4.1 - Security Hardening (Optional Minor Update)
1. **Message Size Limits**
   - Implement 1MB max message size
   - Prevent memory exhaustion attacks
   - Low priority due to localhost-only

2. **Rate Limiting**
   - 100 messages/minute per connection
   - Prevent local DoS
   - Low priority for trusted local extension

#### v0.5.0 - Enhanced Security (If Needed)
1. **Token Authentication**
   - Simple shared secret between extension and app
   - Useful if we ever support remote connections
   - Not needed for localhost

2. **Advanced Origin Validation**
   - Whitelist specific extension IDs
   - Version checking
   - Certificate pinning for extensions

## Rationale

### Why Defer These Features?
1. **Localhost-only = Trusted Environment**
   - Only the user's own browser can connect
   - No external attack surface
   - Extension is trusted code

2. **User Value First**
   - Users want scrobbling to work, not security theater
   - Core functionality more important than edge-case protection
   - Can add security incrementally

3. **Development Velocity**
   - Focus on delivering working features
   - Avoid over-engineering early
   - Iterate based on real threats

### When to Revisit?
- If we add network/remote access
- If users report security concerns
- After core v0.4.0 features are stable
- If we discover actual attack vectors
