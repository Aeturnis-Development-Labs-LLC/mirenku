# Part 2: BYOC (Bring Your Own Cloud)

## Philosophy
**"Your cloud, your data, your rules"** - Mirenku provides zero cloud infrastructure. Users leverage their existing cloud services for multi-device sync.

## Supported Cloud Types

### 1. File Sync Services
**How it works:** Database lives in a synced folder

#### Supported Services
- **Dropbox** - Just point to Dropbox folder
- **Google Drive** - File Stream or Backup & Sync
- **OneDrive** - Built into Windows
- **iCloud Drive** - Built into macOS
- **Box, MEGA, pCloud** - Any service with folder sync

#### Implementation
```python
class CloudFolderSync:
    def __init__(self, cloud_path):
        self.db_path = cloud_path / "Mirenku" / "anime_tracker.db"
        self.lock_file = cloud_path / "Mirenku" / ".lock"

    def acquire_lock(self):
        # Prevent simultaneous access
        while self.lock_file.exists():
            time.sleep(0.5)
        self.lock_file.touch()

    def release_lock(self):
        self.lock_file.unlink(missing_ok=True)
```

```python
class GitSync:
    def __init__(self, repo_url):
        self.repo = Repo(self.local_path)

    def sync(self):
        # Pull latest
        self.repo.remotes.origin.pull()

        # Commit local changes
        self.repo.index.add(['anime_tracker.db'])
        self.repo.index.commit(f"Update from {socket.gethostname()}")

        # Push to remote
        self.repo.remotes.origin.push()
```

## Conflict Resolution

### Detection Strategy
```python
class ConflictDetector:
    def detect_conflicts(self):
        conflicts = []

        # Check file modification times
        local_mtime = self.local_db.stat().st_mtime
        remote_mtime = self.remote_db.stat().st_mtime

        if abs(local_mtime - remote_mtime) < 60:
            # Modified within same minute - likely conflict
            conflicts.append(self.analyze_differences())

        return conflicts
```

### Merge Strategy
```python
def merge_databases(local_db, remote_db):
    merged = {}

    for anime_id in set(local_db.keys()) | set(remote_db.keys()):
        local = local_db.get(anime_id)
        remote = remote_db.get(anime_id)

        if not remote:
            merged[anime_id] = local
        elif not local:
            merged[anime_id] = remote
        else:
            # Take the one with more progress
            if local.episodes_watched > remote.episodes_watched:
                merged[anime_id] = local
            else:
                merged[anime_id] = remote

    return merged
```

## Privacy & Security

### What Mirenku Does
- ✅ Provides sync logic
- ✅ Handles conflicts locally
- ✅ Manages file locking
- ✅ Creates backups

### What Mirenku DOESN'T Do
- ❌ No servers
- ❌ No accounts
- ❌ No data collection
- ❌ No cloud storage
- ❌ Never sees your data
- ❌ No network traffic except localhost

### Security Considerations
```python
class SecurityManager:
    def validate_cloud_path(self, path):
        # Ensure path is safe
        if not path.is_absolute():
            raise ValueError("Must be absolute path")

        # Check permissions
        if not os.access(path, os.W_OK):
            raise PermissionError("No write access")

        # Verify it's actually a cloud folder
        cloud_markers = [
            ".dropbox", "Dropbox",
            "Google Drive", "OneDrive",
            ".icloud"
        ]

        if not any(marker in str(path) for marker in cloud_markers):
            # Warn user this might not be synced
            self.show_warning("This doesn't appear to be a cloud folder")
```
